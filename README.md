# Retail Sales Prediction System

## 1. Introduction

Retail Sales Prediction System is a machine learning project.

This project predicts retail sales using past sales data.

It helps users understand sales performance and make better business decisions.

## 2. Objectives

The main objectives of this project are:

- To predict future sales.
- To analyze past sales data.
- To display sales information using charts.
- To help businesses understand sales trends.
- To use machine learning for sales prediction.

## 3. Features

- Sales prediction using machine learning.
- Sales data analysis.
- Interactive dashboard.
- Monthly sales chart.
- Total sales information.
- Average sales information.
- Easy-to-use interface.

## 4. Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Pandas
- NumPy
- Scikit-learn
- Chart.js
